## React Router 7 (framework mode)

This app uses React Router 7's framework mode on Vite, not Next.js. Its docs ship in `node_modules/react-router/docs/` (start with `start/framework/`). Read the relevant guide before writing route modules, loaders, actions or resource routes.

- Route types come from `./+types/<route>` and are generated by `react-router typegen` (`npm run typecheck` runs it).
- Server-only code goes in `*.server.ts` files so it never reaches the browser bundle.
- Stay on React Router 7.x: v8 is out, but the Vercel preset still targets v7.
